# Bot Decision Policy

Updated: 2026-09-16

## 목적

Sim-Runner의 플레이어 선택을 증강별 고정 휴리스틱이 아니라 하나의 `CandidateAction` 구조로 평가한다.

```text
현재 상태
  -> 가능한 행동 후보 생성
  -> authoritative game rule로 후보 상태 계산
  -> 상태 가치 및 필요 시 기대값/1-step 이동 가치 평가
  -> score, stable key 순으로 결정
  -> 선택된 후보만 실제 실행
```

후보 평가 중에는 실제 RNG와 실제 setup 상태를 소비하거나 오염시키지 않는다.

- AUG-026 보험 들었습니다

- AUG-035 일타쌍피: 추가 잡기 사용 안 함 포함
- AUG-038 대동단결: 모든 기준 그룹과 일반 던지기 비교
- AUG-043 독불장군: 업기, 따로 두기, 아군 잡기 비교

- AUG-056 웜홀: 가능한 모든 그룹과 일반 던지기 비교
- AUG-061 각자도생: 유지와 가능한 모든 집합 분할 비교
- AUG-063 숫자 풀: 가능한 배분량과 일반 이동 비교

## 획득 시 선택

획득 단계도 `CandidateAction`을 사용한다.

- 노출된 3장 중 카드 선택
- AUG-030 에이스 대표 말
- AUG-041 독주 대표 말
- AUG-058 토끼와 거북이 대상 말
- AUG-053 배반으로 넘길 자신의 말

AUG-053의 받는 상대, AUG-048/049의 교체 증강처럼 규칙에 명시된 무작위 요소는 무작위로 유지한다.

카드 후보의 상태 가치가 같을 때는 기존 seeded selection에서 뽑힌 카드를 tie-break 우선순위로 사용해 기존 RNG 재현성을 가능한 한 유지한다.

## 특수 승리 목표 점수

상태 평가는 다음 특수 목표 진행도를 별도 반영한다.

- AUG-031 문워크: 대기 복귀와 역방향 진행
- AUG-032 사방신: 목표 갈림길 점유
- AUG-033 우주의 중심: 중앙 점유, 집결, 접근
- AUG-041 독주: 누적 바퀴와 대표 말 진행
- AUG-042 추노: 누적 상대 잡기

## 실행 계층 원칙

`roll-lifecycle`과 acquisition lifecycle은 CandidateAction이 선택한 행동을 실행한다. lifecycle 내부에서 다시 신의 손 얼굴이나 도 재던지기 여부를 고르지 않는다.

후보 평가에는 복제된 ownership/setup 컨텍스트를 사용하고, 실제 RNG는 최종 후보가 결정된 뒤 실행 시점에만 사용한다. 배반은 전략적 소스 말 선택으로 바뀌어도 기존 RNG 스트림 위치를 유지하도록 과거 소스 선택에 해당하는 RNG 호출을 소비만 하고 버린다.

## 이번 작업에서 바꾸지 않은 것

이번 브랜치는 선택 정책 구조를 통합하는 작업이다. 증강의 규칙 수치와 카탈로그 세대 자체는 변경하지 않았다.

따라서 Production과 Sim-Runner 사이에 이미 존재하던 카탈로그 차이와 일부 규칙 차이는 별도의 규칙 동기화 작업으로 남아 있다. 특히 Sim-Runner의 AUG-044 신의 손 규칙은 현재 Sim 기준 규칙을 그대로 사용한다.

## 남은 모델 한계

`CandidateAction`은 학습형 가치 모델이 아니라 휴리스틱 상태 가치 함수와 제한된 lookahead를 사용한다. 여러 턴 뒤의 장기 전략을 완전히 예측하지는 않는다.

웜홀처럼 결과가 다음 라운드에 확정되는 효과는 현재 웜홀 진입 직후 상태 가치를 중심으로 평가한다. 향후 self-play 데이터로 가치 함수를 학습하더라도 CandidateAction의 행동 생성/실행 구조는 그대로 유지할 수 있다.
